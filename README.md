# 🧪 Java Playground – Lernen, Testen, Weiterentwickeln

Dieses Repository dient mir als persönlicher Lern- und Experimentierraum für Java.  
Hier teste ich gezielt neue Konzepte, vertiefe bestehendes Wissen und arbeite mit modernen Technologien und Tools.

## 🎯 Ziel des Repos

Obwohl ich bereits beruflich als Java Developer tätig war, nutze ich dieses Repository, um mich kontinuierlich weiterzuentwickeln – nach dem Motto: **Learning by doing.**

- Neue Libraries und Frameworks ausprobieren
- Best Practices festigen
- Architekturmuster und Codequalität verbessern
- Saubere Projektstruktur trainieren

---

## 📌 Hinweis

Dies ist kein abgeschlossenes Projekt, sondern eine **laufende Sammlung von Test- und Lerninhalten**.
